# AISystems

Notes on becoming an AI engineer and building production AI systems.

**Start here: [`AI_ENGINEERING_GUIDE.md`](AI_ENGINEERING_GUIDE.md)** — the comprehensive guide that ties everything below into
one path, from foundations to production, with a master index from topic to file.

## Curriculum

- **[`ai-engineer-fundamentals/`](ai-engineer-fundamentals/README.md)** — a six-part, beginner-to-production learning path
  (foundations, classical ML, deep learning, generative AI/LLMs, production AI, capstones), with lessons, exercises and checklists.

## Field manual

- **[`AI_System.md`](AI_System.md)** — complete reference for RAG + agent systems, in build order:
  ingest → parse → chunk → embed → index → retrieve → rerank → generate → evaluate → serve → operate.
- **[`reference/`](reference/README.md)** — the same material broken out one file per scenario,
  each with implementation steps, an example, trade-offs, and production/scale notes.
- **[`GPUResizing.md`](GPUResizing.md)** — standalone playbook for GPU capacity changes in production,
  with finer detail in [`reference_gpu/`](reference_gpu/).
- **`old/`** — earlier drafts, kept for history.
